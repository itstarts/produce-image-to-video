# 通用工作流

## 文案入口

1. 确认目标、观众、平台、画幅、时长和语气。
2. 编写并批准中文旁白初稿。
3. 制定并批准视觉风格。
4. 根据旁白拆镜头，生成角色或产品锚点。
5. 生成一张代表性分镜，确认后生成全部分镜。
6. 做旁白—分镜一致性检查，锁定旁白文字。
7. 请用户录制或提供最终音频。
8. 按实际音频停顿和时长锁定镜头时序。
9. 逐幕交付外部图生视频提示词并检查用户保存的片段。
10. 合成、加旁白、字幕和经批准的声音元素。
11. 自动验证后请用户做最终视觉确认。

## 音频入口

1. 检查音频并转写或核对旁白。
2. 分析总时长、语句和停顿，得到初始镜头时序。
3. 确认目标、观众、平台、画幅和视觉方向。
4. 生成并批准风格、锚点和代表性分镜。
5. 生成全部分镜并锁定镜头清单。
6. 逐幕生成提示词、验收片段并完成后期。

## 回退路径

- 风格样片不通过：只修改风格描述，不批量生图。
- 角色或产品锚点不通过：停在锚点阶段，不生成分镜。
- 代表性分镜不通过：只迭代这一张，保持已批准风格不变。
- 实际音频与锁定文字不一致：让用户选择重新录音或重新批准文字；不要静默剪词。
- 单幕时长超过平台能力：推荐拆幕；只有没有新信息的尾部才能使用静帧补足。
- 片段抖动、变形或错误运镜：生成针对失败证据的重做提示词，不同时改动无关风格。
- 外部平台不可用：保留图片、提示词和状态，允许用户改选平台后继续。

## 状态顺序

```text
需求已确认
→ 旁白初稿已确认
→ 风格已确认
→ 锚点已确认
→ 代表性分镜已确认
→ 全部分镜已确认
→ 旁白已锁定
→ 音频已验证
→ 镜头时序已锁定
→ 片段逐幕通过
→ 成片已合成
→ 自动验证通过
→ 用户最终确认
```
