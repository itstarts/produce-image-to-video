# 通用工作流

## 入口

### 文案入口

1. 确认目标、观众、平台、画幅、时长和语气。
2. 编写并批准旁白初稿。
3. 制定并批准视觉风格；需要固定主体时批准身份锚点。
4. 按语义建立初始场景和视觉节拍，先生成代表性分镜。
5. 代表性分镜通过后生成全部分镜，检查旁白—画面一致性。
6. 锁定旁白文字，请用户录制或提供最终音频。
7. 根据真实音频和词级时间锁定场景时间线。
8. 确认制作模式并执行对应路线。
9. 生成字幕、合成、自动验证并进行最终预览确认。

### 音频入口

1. 验证音频，转写或核对旁白内容。
2. 根据真实时长、语句和停顿建立初始视觉节拍。
3. 确认目标、观众、平台、画幅、语气和视觉方向。
4. 批准风格、身份锚点和代表性分镜，再生成全部分镜。
5. 锁定场景时间线和制作模式。
6. 生成字幕、执行对应制作路线、验证并预览。

## 制作模式决策

只在动作需求和分镜清楚后决定，不根据风格标签自动选择。

| 模式 | 适用情况 | 主要取舍 |
| --- | --- | --- |
| `static_hyperframes` | 叙事靠旁白、构图和摄影机运动成立；不需要人物真实表演 | 最稳定、成本可控、可重复；没有真实口型或肢体动作 |
| `external_clips` | 人物、产品、物体或环境必须发生真实动作 | 动态丰富；成本、漂移和平台操作更多 |
| `hybrid` | 少量重点镜头需要动作，其余镜头适合静态运镜 | 在稳定性和动态表现之间平衡；逐幕管理两类素材 |

用户没有明确偏好时，根据以下问题给出推荐并等待确认：

- 主体是否必须完成可描述的动作？
- 动作失败会不会破坏人物身份、产品结构或信息准确性？
- 用户是否愿意逐幕操作外部平台并重做失败片段？
- 是否需要离线、可重复或低成本地重新渲染？

## 共同依赖链

```text
需求已确认
→ 旁白初稿已确认
→ 风格已确认
→ 锚点已确认（如需要）
→ 代表性分镜已确认
→ 全部分镜已确认
→ 旁白已锁定
→ 音频已验证
→ 场景时序已锁定
→ 制作模式已确认
→ 路线素材已通过
→ 字幕已校时
→ 成片已合成
→ 自动验证通过
→ 最终预览已接受
```

## 路线执行

### `static_hyperframes`

1. 为每幕确认一张或多张批准图片及其景别顺序。
2. 为每幕选择或确认确定性运镜；默认不生成主体局部动作。
3. 对齐字幕并检查全文、边界和后段累计漂移。
4. 生成新的 HyperFrames 项目目录。
5. 运行完整 `check`，按场景中点抽帧并目视检查。
6. 获得最终预览接受后再高质量渲染和验证。

### `external_clips`

1. 确认平台和保存位置。
2. 每次交付一幕的图片、目标时长、提示词和文件名。
3. 每幕片段完成后检查规格、动作、身份、结构、黑帧和音轨。
4. 全部片段人工接受后统一规格、拼接、加旁白和字幕。

### `hybrid`

1. 每幕记录 `production_strategy`：`static_image` 或 `external_clip`。
2. 先完成外部片段门禁，再生成统一 HyperFrames 合成项目。
3. 外部片段保持静音；旁白使用独立音轨。
4. 对静态图和视频片段共同执行时间线、转场、字幕和快照检查。

## 回退路径

- 风格样片不通过：只修改风格描述，不批量生图。
- 身份锚点不通过：停在锚点阶段，不生成分镜。
- 代表性分镜不通过：只迭代代表镜头，保持已批准不变量。
- 音频与锁定文字不一致：重新录音或重新批准文字；不静默剪词。
- 字幕后段逐渐超前或滞后：检查是否错误应用全局时长缩放；回到词级时间，不手工平移全部字幕。
- 静态镜头停留过久：按语义或景别增加图片，不通过更剧烈的无意义运镜掩盖。
- 外部片段抖动、变形或错误运镜：针对单一失败重做，不同时改变题材和风格。
- 外部平台不可用：保留图片、提示词和状态，切换为静态路线或由用户另选平台。
- HyperFrames 检查失败：停止预览和渲染，修复实际错误后重新检查。
