# 风格制定与 Image Gen

## 风格来源

- 无参考：根据题材、观众、平台、情绪和图生视频稳定性提出 2～3 个方向。
- 有参考图：把每张图标注为风格参考、身份锚点、编辑目标或辅助素材。
- 有品牌规范：提取可执行的颜色、字体、构图、摄影和禁用项，不发明品牌规则。

## 风格配置字段

```text
媒介与表现形式
主体和角色设计
形状语言
构图和镜头语言
光线与情绪
色彩系统
材质与纹理
背景系统
细节密度
后续动画友好性
必须保持
禁止出现
```

不要把某个故事、固定画风或固定色板写成默认值。

## Image Gen 提示词结构

```text
用途：<插画故事/产品演示/科普等>
资产类型：16:9 图生视频分镜图
主要画面：<本幕唯一的主要信息>
输入图片：<每张图的角色>
场景与背景：<环境>
主体：<人物、产品或对象>
风格与媒介：<已批准风格配置>
构图与镜头：<景别、位置、留白>
光线与情绪：<光线和情绪>
色彩：<已批准色彩系统>
材质：<表面和纹理>
必须保持：<身份、品牌、服装、比例等>
禁止出现：文字、水印、额外主体、重复肢体、未批准风格等
```

## 一致性门禁

- 固定人物或产品时，先生成身份锚点并由用户确认。
- 后续分镜把已批准风格样片作为风格参考，把锚点作为身份参考。
- 每次重复写清不可变化的脸型、发型、比例、服装、产品结构、颜色和品牌元素。
- 迭代时一次只改一个目标，并重复所有不变量。
- 构图要为动画留出空间：主体轮廓分离、关键对象完整可见、避免手脚和道具严重重叠。
- 不在图片里生成字幕；字幕由后期添加。

## 保存与版本

- 项目图片必须复制到工作区，不能只保留在 Image Gen 默认目录。
- 使用 `images/style/`、`images/anchors/` 和 `images/scenes/` 分类。
- 已确认图片不覆盖。使用 `-v2`、`-v3` 迭代，并在状态文件中只指向当前确认版本。
- 每次报告使用的最终中文提示词、内置或备用生成路径，以及实际保存路径。
