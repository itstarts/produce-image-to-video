# 质量门禁

## 旁白与音频

- 音频可完整解码，并记录真实时长、采样率和声道。
- 朗读内容与锁定旁白一致；差异必须由用户选择重新录音或重新批准文字。
- 没有不可接受的削波、长静音或中断。
- 场景时间线覆盖音频且不裁断旁白；误差超过容差时先修正场景，不静默缩放词级时间。

## 图片

- 主体、情绪和信息与本幕目标一致。
- 风格、配色、材质和构图符合已批准配置。
- 固定人物、产品或品牌结构一致。
- 没有多余主体、重复肢体、乱码、非预期文字或水印。
- 主体轮廓、景别和留白适合已选制作模式。
- 图片已复制到项目并记录最终提示词和实际路径。
- 自动检查不能替代用户视觉批准。

## 外部片段

- 文件存在并可完整解码。
- 视频流、分辨率、画幅、帧率和时长符合项目要求。
- 有与提示词一致的有效动作，不把编码噪声当作动作证明。
- 没有明显全局抖动、意外缩放、错误运镜或黑帧。
- 人脸、肢体、产品结构、文字和品牌没有明显变形。
- 音轨符合要求；混合或后期使用时删除平台自动音频，只保留批准的独立音轨。
- 自动验证后仍需用户逐幕接受。

可运行：

```bash
python <skill-dir>/scripts/validate_media.py <clip> --decode --count-unique-frames
```

唯一帧数量只能排除完全静止文件，不能证明动作质量。

## 字幕

- 字幕有效字符按顺序重建锁定旁白，不使用识别错误替换原文。
- 每条开始时间早于结束时间，条目不重叠，且不越过音频时长。
- 词级时间直接来自音频；禁止为了对齐总时长应用会产生累计漂移的全局缩放。
- 书名、专有词及用户配置的保护词不被拆开。
- 单行/多行、每条长度和标点规则符合已批准 `captions.policy`。
- 字幕在安全区内，背景、描边、字号和字体符合已批准样式。
- 至少检查开头、中段、后段和最后一句的实际同步。

## HyperFrames 合成

- 生成项目固定精确的 HyperFrames CLI 版本；版本为空时不得生成可交付项目。
- 合成不依赖运行时网络获取必需图片、视频、音频、字体或动画库。
- 所有视觉运动可 seek、确定性且不使用时钟、随机数或事件状态。
- `npm run check` 通过，错误和警告均已审阅。
- 每个场景至少抽取一个可见中点；检查图片、外部视频、裁切、转场、字幕和背景。
- 静态图片只做批准的摄影机运动，不伪造人物口型或肢体动作。
- 检查通过只允许进入最终预览，不等于用户批准渲染。

## 成片

- 所有已批准镜头按正确顺序出现，没有漏幕或错误重复。
- 视频流和音频流完整解码。
- 总时长与锁定时间线一致，旁白没有裁断。
- 字幕与实际语音同步并处于安全区域。
- 没有黑帧、明显拼接断裂、错误转场或异常静止。
- 报告输出路径、编码、分辨率、帧率、音轨、时长和文件大小。
- 区分：已渲染、自动验证通过、最终预览已接受和用户最终接受。
