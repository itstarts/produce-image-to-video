# 质量门禁

## 图片

- 主体、情绪和信息与本幕目标一致
- 风格、配色、材质和构图符合已批准配置
- 固定人物、产品或品牌结构一致
- 没有多余主体、重复肢体、乱码、文字或水印
- 可动画元素轮廓清楚且没有不必要的严重重叠
- 用户明确接受视觉质量

## 单幕视频

- 文件存在并可完整解码
- 视频流、分辨率、画幅、帧率和时长符合项目要求
- 有可感知的有效动画，不把编码噪声当作动作证明
- 没有明显全局抖动、意外缩放、错误运镜或黑帧
- 人脸、肢体、产品结构、文字和品牌没有明显变形
- 动作顺序与旁白和提示词一致
- 音轨符合要求；平台自动加入声音时明确报告并按需制作无声副本
- 自动检查通过后仍需用户视觉确认

可运行：

```bash
python <skill-dir>/scripts/validate_media.py <clip> --decode --count-unique-frames
```

唯一帧数量只用于排除完全静止文件，不能代替视觉检查。

## 音频

- 可解码并记录真实时长、采样率和声道
- 内容与锁定旁白一致
- 没有不可接受的削波、长静音或中断
- 场景目标时长之和与音频时长匹配；差异超过容差时先调整清单

## 成片

- 所有已批准镜头按正确顺序出现
- 视频和音频完整解码
- 总时长与锁定时序一致
- 旁白没有被静默裁断
- 字幕与实际语音同步，并处于安全区域
- 没有漏幕、黑帧、重复错误帧或明显拼接断裂
- 输出路径、编码、分辨率、帧率、音轨和文件大小已报告
- 区分自动验证通过与用户最终确认
